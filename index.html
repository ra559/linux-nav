LEARN AS YOU GO

Command guide

Keep the command reference nearby, or give yourself more room to explore.

pwd

Print working directory. It answers: “Where am I?”

ls

List the files and directories around you.

ls -l, ls -a, and ls -la add detail or show hidden items. Try man ls to read about more options.

cd

Change directory — walk to another place.
